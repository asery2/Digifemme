# Mon Projet en Go

Ascii-art-color

## Description

Le but de ce projet est de créer un programme en Go permettant de manipuler les couleurs dans une sortie texte. Elle prend en charge la coloration des lettres dans un art ASCII en fonction des paramètres spécifiés.

## Utilisation

go run . --color=<color> <letters to be colored> "<text>"

- <color> : spécifie la couleur à utiliser pour la coloration (voir les couleurs disponibles dans le code).
- <letters to be colored> : spécifie les lettres à colorer.
- "<text>" : spécifie le texte à convertir en art ASCII.
